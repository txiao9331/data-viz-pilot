# 公共池 Demo · 连续线迹版本设计简报

## 一句话概念

一个移动核心不断释放粒子，每个粒子用连续短线连接自己的历史位置，逐渐叠加成原 pilot 式的复杂紊乱线团；日常身体数据改变生成、流动、寿命与颜色，而不伪装成真实观展逐秒测量。

## 本轮需求清单

- 使用最近一个月全部有效日汇总：静息心率、血氧、压力。
- 移除睡眠数据及其粒子数量映射。
- 将日汇总平滑插值为模拟连续参数，明确数据边界。
- 粒子具备生成速度、存活时长、局部运动速度、淡入与消散。
- 保留原 pilot 的“上一位置 → 当前位置”连续短线，同时在单点核心模式补充可见的发散粒子点与点状轨迹。
- 点与线仍沿同一条三维观展路线生成，保留展厅，不变成与空间无关的全屏噪声。
- 每个作品前的停留时间为独立模拟参数，停留处逐渐形成缠绕线团。
- 路线拐角平滑，核心和镜头运动连续，不穿展台。
- 保留低位跟随、俯视、暂停、继续和重新开始。
- 保留桌面端 Edit3D 预览与既有展厅、自由行走和镜头场景。

## 数据与体验边界

- 数据窗口为 2026-08-20 至 2026-09-18，共 30 天。
- 30 天日汇总映射到 50 秒重演，相邻日期使用平滑插值。
- 插值后的逐帧数值是模拟视觉参数，不是真实观展逐秒生理数据。
- 路线、作品停留、绕行和返回均为模拟空间参数。
- 缺测处理只针对需要的三项指标；本月这三项完整，睡眠缺测不参与。

## 粒子与线迹结构

1. **移动核心**：个人阶段固定采用一个压力色相光点表示“我”的当前位置，不再提供粒子群或无核心模式。
2. **发散粒子**：显示与现有发射记录一一对应的粒子头。粒子从核心向外运动，流动粒子按寿命淡出，较低频的记忆粒子沿路线保留；颜色从出生时压力色随年龄转向当前压力色，并叠加有限的寿命色相偏移，不另造独立随机动画或随机闪烁。
3. **流动线迹**：按静息心率驱动的生成速度出生；每条粒子记录保存最近 3.57 秒的历史折线，只连接同一粒子的相邻采样，按血氧驱动的寿命消散。
4. **路径线迹记忆**：移动与停留过程中以较低频率留下短线，保留到本轮结束，使已走路线和停留缠绕持续可读。
5. **停留线团**：作品前从路径发射切换为局部盘旋与卷曲；已出生的粒子继续运动，不停帧。

### 已确定的个人阶段形态

- 固定为“单点核心＋发散粒子＋连续线迹”，不再显示形态切换按钮，`1／2／3` 快捷键及粒子群核心计算均已移除。
- 路线、身体数据、发射记录、颜色、线迹与作品注视镜头保持既定版本不变。
- 固定版本已在 23 秒实际查看并验证：783 个活跃粒子、782 个发散点，数字键不改变形态，重复定位误差为 0。

## 映射规则

| 输入 | 视觉参数 | 建议范围 |
|---|---|---|
| 静息心率 | 生成速度 | 20—50 个／秒 |
| 静息心率 | 局部流动速度 | 0.08—0.32 m/s |
| 血氧 | 流动粒子寿命 | 6—12 秒 |
| 血氧 | 路径记忆亮度 | 低亮度范围内连续变化 |
| 压力 | 扩散、扰动、局部旋转 | 压力越高越分散 |
| 压力 | 色相 | 190°→20° |
| 粒子年龄 | 发散粒子色相过渡 | 出生压力色→当前压力色；流动寿命偏移最高 54°，记忆 36 秒内偏移最高 36° |
| 模拟停留 | 发射模式与局部聚集 | A 2 秒、B 6 秒、返回 B 2 秒、D 1.5 秒 |

当前出生记录容量为 2499。固定单点版本在 0、12、23、50 秒的活跃数量分别为 1、422、783、1055，发散点分别为 0、421、782、1054。发散粒子头是这些既有记录的另一种可见表达，不重复增加活跃数量。50 秒时有 800 条记忆记录、32429 段记忆短线和 8628 段流动短线。所有记录使用固定随机种子和绝对时间，保证 seek 可重复。

## 路线与镜头

- 总时长 50 秒，30 天数据均匀映射到整条时间轴。
- 移动段使用三次 Hermite 曲线；内部路径点保持连续切线，A／B／D 与出口到点速度归零。
- A 在 2 秒停留内从来向平滑转向 B 的方向，出发时不再切换朝向；朝向使用独立的视线插值，不在零速端点直接切换 Hermite 切线。
- C 使用连续绕行动线，目标点前后切线缩放为 28%，到点速度约 0.254 m/s，而不是以原速冲入绕行。
- D 前的长横移分配 4 秒，D 停留调整为 1.5 秒；总时长与节点顺序不变。
- 返回 B 保留独立路径，不与第一次到访完全重合。
- 跟随镜头对位置与观察目标同时阻尼，避免拐角突然跳转。
- 俯视用于检查完整路径、线迹记忆和节点聚集。

### 本轮镜头调整与后续景深方向

- 低位视野角调整为 48°，镜头高度 1.54 米；路线朝向只控制机位，作品位置控制视线，避免参观时镜头一直沿运动方向看路。
- 注视顺序为 A → B → C → 返回 B → D → 出口；每次切换开始后的 1.2 秒内使用 smoothstep 从上一目标平滑转向当前目标。离开作品时身体可以先转向路线，视线不必同时甩向下一路径点。
- 基础跟随距离移动时 2.6 米、停留时 2.15 米；靠近作品时按空间距离逐渐缩短，最低缩放至 62%，让第一视角更集中于“我”与正在观看的作品。
- 相机位置与观察目标分别使用 4.2／6.0 的指数阻尼；转向分布在停留和路径连接段，不用突然推近制造集中感。
- 相机目标位置与实际位置都受墙面和作品安全边界约束；作品使用 1.18 米径向净距，避免阻尼插值穿过展台。
- 已实际查看 4 秒 A、13 秒 B、23 秒 C、44.5 秒 D 与 6 秒 A→B 转场，作品均保持在画面主体区域。五次作品切换各连续检查 90 帧，无穿墙；最小镜头—作品中心距离约 1.324 米，23 → 4 → 23 秒重复定位误差为 0。
- 本轮完成焦距与运动曲线；真实景深仍留到后续渲染阶段验证，不能只修改光圈数值就声称已有景深。

## 视觉与材质

- 当前展厅、展台、作品与固定装置统一为白色／暖白色纯色材质，降低环境亮度，让连续线迹成为主要轨迹表达。
- 核心与发散粒子使用柔边点精灵；发散层为独立 `THREE.Points`，流动与记忆分别使用独立 `THREE.LineSegments` 层和逐顶点颜色、透明度。
- 每条线迹保留 42 个历史步长；WebGL 原生线宽受限，因此用透明度和持续叠加表现年龄衰减，不依赖粗辅助线。
- 自定义线条 shader 同步对数深度，避免线迹被地面与展台错误遮挡。
- 发散粒子按出生压力色、当前压力色和存活时间连续改变色相，并通过亮度衰减与加色混合表现消散；连续线迹保留出生色。

### 白色暗场首轮渲染原则

- 白色材质以低明度差异和粗糙度区分层次，不使用纹理细节争夺注意力，也不把网格文字或灯具做成额外发光体。
- 取消全局方向主光，仅保留低强度环境光与 A／B／C／D 四盏微弱聚光灯，使空间退后而作品仍有局部光区。
- 粒子核心、发散点与线迹保持身体数据色相，通过加色混合和不受场景灯光影响的材质形成自发光观感；当前没有后期 Bloom，不把直接亮度描述为后期辉光。
- 控制聚光灯、长期线迹叠加与高密度线团的亮度，避免白色作品过曝或停留区域失去线条细节。
- 首轮已经完成个人低位、公共池俯视与第一视角的对照检查；后续只在交付测试中微调，不重新改变已确定的数据和空间体验。

## 交互与 HUD

- V 切换低位跟随／俯视，Space 暂停／继续，R 重新开始；个人阶段不再提供核心形态切换。
- HUD 显示当前时间、阶段、进度和三项模拟连续参数。
- 固定说明：“近一个月真实日汇总驱动 · 连续变化与空间路径为模拟”。

## 编辑与制作路由

- 既有展厅、展台和材质继续由 Three.js 维护，不新增 Blender 模型。
- 路线、粒子、线迹、数据和交互属于实时生成内容，全部由 Three.js 实现。
- 保持 `particle_body`、`particle_trail` 与 `particle_memory` 注册 ID 稳定，新增 `particle_emission` 对应单点核心的发散粒子层。

## 验收画面与性能

- 低位跟随：移动核心、连续流线和 HUD 可读，局部紊乱与空间位置同时可辨。
- 俯视：路径线迹、C 绕行和返回 B 可辨认，停留处形成明显线团。
- B 长停：局部盘旋持续运动，已出生粒子不冻结。
- 绝对时间 seek 后位置、颜色、线段数量与实际画面一致。
- 路线安全检查覆盖整条 50 秒时间轴，运行保持流畅。

## 公共池阶段 2B 扩展 · 36 人路线偏差对照

### 需求与边界

- 数据生成阶段将全部 36 位模拟观众放入同一个公共池，保留 R1 的多数优势，同时看见其余 15 人的路线偏差；阶段 2C 起运行时 `V001` 绑定个人重演，其余 35 人仍为模拟。
- 个人重演保持固定单点版本；公共池仍使用共享 Points／LineSegments 层，不为每位观众复制完整个人系统。
- 数据生成阶段的路线和身体数据全部为模拟；运行时自我使用真实日汇总与模拟空间路线。颜色继续表达身体压力，不新增路线颜色，避免混淆视觉编码。

### 四条路线的统一映射

| 路线 | 人数 | 空间路径 | 时间映射 |
|---|---:|---|---|
| R1 | 21 | 入口 → A → B → C → 返回 B → D → 出口 | 保留现有逐访客实际节点时间 |

- 背景与雾色 `#060807`，环境贴图强度 0.12，半球环境光 0.22；四盏白色聚光灯距离 7 米、半角 30°、衰减 1.5、半影 0.75。初始强度 10 在俯视中偏亮，实测后最终统一调整为 7。
