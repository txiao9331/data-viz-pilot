# 阶段 2A · 公共池模拟数据

## 状态与边界

阶段 2A 数据与阶段 2B 公共池画面均已完成。当前三维画面纳入全部 36 位模拟观众，同时呈现 R1 多数路线与 R2／R3／R4 的少数偏离。个人重演保持不变。

36 位观众、身体参数、空间路线、停留和聚合结果全部为模拟；没有新增人体数据采集，也不包含姓名、邮箱或账户信息。固定种子为 `20261101`，统一时间轴为 50 秒。

## 表达覆盖标准

| 需要表达的内容 | 数据中的对应证据 |
|---|---|
| 多数选择形成公共池骨架 | R1 主路线 21 人，占 58.33%，为绝对多数 |
| 公共池不是所有人的简单叠加 | R2／R3／R4 共 15 人，保留路线偏离，可与主路线区分 |
| 长停留形成热区 | B 累计停留 282.239 秒，明显高于其他作品 |
| 身体抽象仍有差异 | 每位观众有独立的模拟心率、血氧、压力与波动参数 |
| 结果可解释、可复算 | 人数、路段和停留统计均可从观众记录重新计算 |
| 不把模拟伪装成研究采集 | 所有记录带有 `visitor-simulated`／`route-simulated`／`aggregate-simulated` 标记 |

## 文件与用途

- `src/data/pool-routes.json`：4 种路线、节点顺序、基础移动与停留时长。
- `src/data/pool-visitors.json`：36 位观众的入场、速度、身体参数、逐节点停留和经过路段。
- `src/data/pool-aggregate.json`：主路线、少数观众人数、路段人数、作品停留热区及身体参数范围。
- `scripts/generate-pool-data.mjs`：固定种子生成上述三份数据。
- `scripts/validate-pool-data.mjs`：从生成后的 JSON 独立复算并验证统计口径。

## 核心数据字段

### 观众

- `id`：匿名编号 `V001`—`V036`。
- `routeId`：R1—R4。
- `entryDelay`／`exitTime`：在 50 秒时间轴内的入场与离场时间。
- `paceScale`／`scheduleScale`：个体移动速度与时间压缩系数。
- `randomSeed`：后续视觉粒子复现使用的独立种子。
- `body`：模拟心率、血氧、压力、波动幅度与相位。
- `visits`：作品、到访次序、到达、离开和停留时长；B 可有第二次到访。
- `traversedEdges`：该观众经过的路段。

### 聚合

- 完整路线按观众人数统计；主路线为 R1。
- 路段按独立观众人数统计，同一人重复经过不重复增加人数。
- 作品热区使用累计停留“人·秒”，重复观看计入总停留。
- 同时保留单次平均与单人均停留，避免把到访人数误读为停留强度。


## 阶段 2B 实现与验收

- `src/pool-scene.js` 纳入全部 36 位观众；`src/pool-route.js` 将各人的实际节点时间映射到四条平滑路线。R2 跳过 C，R3 使用独立 A → C 段，R4 使用独立 C → D 段。
- 以 `body` 和 `randomSeed` 驱动可复现的个体差异，以节点 `heatWeight` 加权记忆线迹；lane 偏移让共享路段中的个体不完全重合。
- 23 秒时 36 人全部在场，各路线在场为 21／7／5／3，共 5363 个活跃记录、46871 段流动线、64896 段记忆线；50 秒时 25 人尚未离场，共 8823 个活跃记录、43576 段流动线、155714 段记忆线。
- 已逐一探测所有观众的作品到达点，最大误差约 0.51 米，来自有意保留的 lane 偏移；每条路线 201 个时间采样均无非有限坐标。
- 已查看 23 秒俯视与低位、50 秒完整路线俯视。首次 36 人全路径画面出现 D 与 A 过亮，降低长期叠加亮度后复查，作品与线迹可辨。
- 暂停、继续、V、R 与 `23 → 4 → 23` 重复定位通过，两次最终 23 秒俯视截图 SHA-256 均为 `06ac91cc7a4862f344222782c1ada17709ef07433dca97565f552160cd784a33`。
